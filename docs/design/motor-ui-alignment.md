# Motor 界面对齐

参考源：`/Users/crate/Works/ruby/motor/frontend/src`。用户要求尽可能对齐偏好设置、用户中心、header 功能图标和登录页面。在现有 `feat/arco-design-vue` 分支继续，保留所有已有修改，不提交、不发布，不编辑 src/apps 或参考仓库。

## 方向

采用参考源码的布局、控件层次、图标、状态与响应式规则，并连接当前 Go API。只迁移皮肤会留下不可用控件；整套替换 Motor 的 Rails 会话/权限模型则会破坏现有契约，因此使用共享偏好 store 和明确的界面组件对接当前路由、权限与 API。此选择来自用户指定的参考和当前工程约束。

## 对齐清单

1. 偏好面板：480px 桌面抽屉、手机全宽，外观/布局/快捷键/通用/拓展五组；重置、固定、复制；主题模式/色板/自定义色/圆角/字体/密度；侧栏与 header 深浅；三种布局、内容宽度、侧栏显隐/宽度/拖动/悬浮展开/折叠入口；header、面包屑、多页签与 footer 选项；语言、时区、页面标题/进度/切换动画；水印和本地锁屏。
2. Header：统一 HeaderIconButton，搜索/最近访问、语言、主题、全屏、锁屏、偏好；有头像回退与角色信息的账户菜单；手机可用，键盘焦点与 tooltip 清楚。
3. 登录页：参考的双栏故事区与表单、主题/色板/语言/表单左中右布局；保留 Go 验证码、错误恢复、提交防重、安全站内跳转；不保存密码或假造第三方登录。
4. 用户中心：参考的侧栏身份卡、分组导航、主编辑区、资料/安全/界面偏好；连接现有资料、头像、密码接口，头像更新同步 header；保留编辑失败恢复、密码校验、移动布局与双语。
5. 所有可见偏好必须作用于实际界面并持久化，重置同时还原画面和存储。不得添加无效果开关。隐藏 header/侧栏后仍有恢复偏好的入口。

## 本轮补充要求

用户要求修复偏好控件未跟随主题色、菜单分组与页面图标不协调、菜单编辑图标不可选择和编辑布局不协调。已明确选择直接使用 Arco 图标库，不做旧 SVG 兼容映射。菜单图标使用 Arco 原生名称；导航、表格与选择预览共享 18px 图标组件。编辑表单分为基本信息、路由与展示、权限三组，滚动内容与固定可见的操作区分离。


## 监控页与账户菜单补充

监控页使用 ECharts 横向条形图比较 CPU、内存、磁盘的当前使用率，配有可供辅助技术读取的数值明细；网络收发、主机信息与 Go 运行环境分别展示。所有数值来自现有接口，不构造历史曲线或使用接口硬编码的云厂商位置作为事实。

采样串行执行，完成后等待 5 秒；隐藏标签页和离开缓存路由时停止轮询。关闭自动刷新后，返回路由或标签页不再自动请求；失败保留上次成功采样并明确提示，等待手动重试。缺少指标显示未知，不伪造零值。图表跟随 Arco 主题与语言重绘，尺寸由 ResizeObserver 同步。

头像操作菜单取消 Arco 默认的 200px 内部高度限制，四个入口可直接看到。
