# Arco Design Vue 迁移约定

用户要求在新分支将前端框架调整到 Arco Design Vue，偏好 Arco 的组件与样式，并要求逐模块拆解执行。

采用 Arco 原生组件与默认视觉语言，保留 Vue 3、Pinia、现有路由、API、权限、国际化及离线部署。继承现有 polish 的会话保护、选择状态、键盘与窄屏修复。迁移过程中允许两个库短暂共存；最终交付移除 Element Plus、对应图标、注册、类型和样式。不建立一套名为 Arco、实际维持 Element API 的永久兼容层。

公共组件继续服务明确职责：PageContainer、ProTable、分页、表单会话、确认消息和导航。表格列迁移为 Arco 的 title/data-index/cell 插槽；业务 actions 继续接收 row，ProTable 在边界转换 Arco record。表单使用 Arco 校验契约，校验错误必须阻止提交。退出确认取消不作为错误提示。

默认视觉采用 Arco 蓝色、原生圆角与组件密度；深色采用 body 的 arco-theme 属性，业务语义 token 映射 Arco 变量。保留用户的语言、主题偏好及导航内容。不增加新业务、全局 footer 或替换产品文案。

基线 HEAD 7e8d264；从 fix/frontend-polish 创建 feat/arco-design-vue。已有未提交修改保留，备份见 .impeccable/migration/arco-baseline/。不自动提交、推送或部署。

## 落地范围

- 基础设施：原生 Arco 注册、消息与确认框、双语组件语言包、原生色阶与深色主题。
- 应用骨架：登录、侧栏、顶部导航、面包屑、页签、搜索、账户/语言菜单和设置抽屉。
- 共享组件：ProTable、分页、移动卡片/筛选面板、表单校验与提交会话、弹窗和抽屉。
- 业务页面：用户/部门/角色/岗位/菜单/字典/配置/API/日志、任务调度、代码生成与导入、个人资料/密码/头像、仪表盘及监控。
- 清理：Element Plus 与图标依赖、全局注册、语言与主题桥接、旧样式/字体、临时迁移兼容组件和无引用 Vue 2 表单设计器代码均已移除。

## 实施决策与边界

1. 既有 WIP 保留在新分支并另存基线补丁；没有提交或发布。审查需区分基线 polish 与迁移增量。
2. 迁移中暂留 Element 与 Legacy 表格/表单，逐模块替换后删除。双库阶段的体积不作最终数据。
3. 原生 `@arco-design/color` 固定版本直接提供色阶，避免手算主题；代价是保留一个小型直接依赖。
4. 系统管理先迁移简单表单，再处理树形权限页面；只调整模块内部顺序，先验证共用契约。
5. Arco 负责组件外观与 API。AppTabs/AppDropdown 补充 ARIA、键盘操作与非活动内容隔离；弹窗、抽屉、确认框补充焦点进入/循环/回归。适配依赖少量 Arco DOM 类，升级组件库需重跑相关浏览器测试。
6. useFormLocale 只刷新已经显示的校验错误，保证切换语言后不残留旧文案。
7. 删除的 Vue 2 设计器辅助代码没有活跃引用；Swagger 与在线表单设计器仍是后端提供的 iframe，前端只迁移容器。以后恢复旧辅助代码需从 Git 历史取回。
8. 接口字段类型保持原契约：Checkbox 与字符串标记显式转换，树/穿梭框选中值回转业务 ID，分页/排序转换在共享边界完成。
9. Chrome mock 测试验证前端流程及 multipart 上传请求，不向实际后台执行写操作；不将其表述为生产上传、真实设备或屏幕阅读器认证。

独立审查发现的桌面栅格、部门搜索和模态键盘焦点问题均以失败用例复现后修复。另补齐上传前钩子、搜索框焦点 API、刷新图标宽度及深色导航对比度回归。

原有 Helvetica 系统字体保持，并沿用既有精确值 `overused-font/Helvetica` 忽略；没有增加整文件或整条规则忽略。头像裁剪器原有空白工具按钮未归因于本次迁移；本次没有扩展重设计。768px 的密集表格仍保留既有列收缩策略。
