# 网络检查

Mode: Operate. Audience: 网络管理员。任务：从当前后端检查目标的连通性、路径和吞吐量；需要时开启临时 iPerf3 端口供客户端连接。

范围：网络管理 → 网络检查。工具 ping、mtr、nexttrace、iperf3、traceroute；默认后端执行；iPerf3 同时支持客户端和临时服务端。参考 https://lg.dmit.sh/?server=lax-eb 的操作组织，保留 motor 的 Arco 界面及用户外观偏好。

## Direction contract

THESIS: 一眼确认执行服务器，选工具、填目标、看原始输出；检查工具和实时结果构成页面主线。

OWN-WORLD: Motor 外壳、原生 Arco 控件和用户外观偏好保持现状。按本轮用户恢复 DMIT 回显质感的要求，输出区使用局部深灰表面、等宽排版与真实字段着色；操作栏保持紧凑，不复用 CRUD 等宽筛选栅格。

STORY: 确认当前后端和可用工具，输入目标，开始检查；在同一区域跟随输出、停止、复制或下载。iPerf3 默认后端连接目标，临时端口模式展示连接命令和倒计时。轮询失败保留任务与输出，恢复只读状态不重发测试。

FIRST VIEWPORT: 单栏构图，上方节点→命令→目标→IP 协议→执行组成连续操作栏，目标占弹性宽度；下方完整深灰输出区。执行中原位显示停止，复制和下载收为图标。活动 iPerf3 会话横向展开，不压缩输出宽度；低频节点资料继续通过信息浮层访问。

FORM: 以用户提供的 DMIT 回显原图及本轮 shape 后调用 polish 为方向依据。保留五工具、后端默认执行、iPerf3 双模式和任务契约，精修本页构图、排版与状态呈现。没有新增品牌、图片资产或共享主题。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Evidence contract

验证桌面/手机、明/暗主题、中文/英文、默认 ping、IPv6 长输出、iPerf3 双模式、停止、下载、权限不足、缺少工具、轮询失败与恢复、路由恢复及键盘选择。截图中 192.0.2.1/2001:db8 为自动化测试的合成数据，不作为真实网络结果。实际后端回环地址的运行证据见[网络检查验证记录](../../docs/NETWORK_DIAGNOSTICS_VALIDATION.md)。没有新增 shipping raster，现有 DESIGN.md 与 design.json 保留。

## Historical implemented surface

本页是既有视觉世界的普通扩展。[DESIGN.md](../../DESIGN.md) 与 [design.json](../design.json) 继续是共享系统记录；认证故事栏、认证色阶和认证页面构图不移植到本页。这里记录实际页面的局部取值，不生成新的全局设计 token。

- **表面与状态**：普通面板、边框、说明文字消费原生 Arco 令牌；普通面板、终端分别使用 Motor sm/md 圆角映射，不增加投影。主操作、次级停止、工具可用性及警告沿用原生语义色；终端内部使用下述固定材料和字段色。
- **文字**：正文继承本地系统字体栈。页面标题使用 Motor 20 字号 token，区域标题及正文使用 14，辅助文字使用 13/12。终端命令及原始输出共用本地等宽字体、13 字号 token、1.5 行高，主机及状态使用 12。数字使用等宽数字；不加载新字体。767px 以下输入采用 `max(16px, var(--motor-font-size-14))`。保存 18px 偏好后，浏览器确认输入为 18px、终端正文为 17px。
- **布局**：全宽工具栏内边距 12px、控件间距 8px；节点选择及信息按钮共同占 240px，目标占弹性空间。容器不超过 820px 时节点独占首行，不超过 600px 时其余控件排成两列，359px 以下改为单列。默认终端与工具栏等宽，无空白侧栏；仅 `state.busy(session)` 为真时桌面采用 `minmax(280px, 1fr) minmax(0, 1.85fr)`，991px 以下仍单列。切换布局不重建终端实例。所有断点保持节点→工具→目标→协议→执行的 DOM 与视觉顺序。
- **信息密度**：取消常驻服务器卡片、独立来源条、页面副说明、普通工具说明、重复来源说明及空闲会话。缺工具和无权限直接在操作区提示，缺工具可重新获取状态；节点加载失败的重试不依赖详情浮层。节点选择只展示 API 返回的当前节点，没有虚构选项。完整命令通过终端摘要展开，保留时间通过下载提示查看。过期、中断、截断与结束说明统一进入终端状态区；过期/中断时不沿用旧的“执行中”及递增时长。
- **可操作性**：767px 以下运行、停止、复制/下载、关闭会话、详情与恢复按钮及选择器至少 44px 高。节点详情使用原生 Arco 点击浮层，打开后聚焦内容，关闭或 Esc 后回焦信息按钮；宽度限制在视口内，IPv6 可换行。会话与完整命令继续使用原生 `details/summary`。原始行保持空格、换行与列对齐，仅在输出区内滚动；命令可换行。终端高度为桌面 `clamp(360px, calc(100dvh - 280px), 560px)`、手机 `clamp(360px, 56dvh, 480px)`。标题、命令摘要和底部状态独立布局，不覆盖日志；长完整命令有高度上限。跟随关闭时保留手动位置，重新开启时滚至末尾。
- **状态连续性**：普通检查与临时 iPerf3 会话各自保留任务。更新中断时继续显示已有输出和“状态待确认”的说明；恢复更新只读取任务，不重发检查。离开缓存页暂停轮询，返回时读取已保存的任务标识。所有界面文案位于中文、英文语言包。

目标输入的占位文字已在本页表单范围映射到 `--color-text-2`，不改变共享输入组件或认证外壳。独立 finish review 回传的亮色测量为 6.40:1（背景 `#f2f3f5`）；修正后的空态截图已纳入文档核对。

## Terminal palette boundary

本节保留此前终端配色及测量记录；其中装饰圆点属于历史实现，当前源码已无这些圆点。下列历史对比度和旧扫描结论不替代本次当前截图及 detector 范围，也不新增全站规则。

用户提供 DMIT 实际回显截图后，终端改为统一的 `#282a36` 表面；局部 `--terminal-*` 变量仅供结果组件使用，不扩充共享色板。所有字段仍保留原文、单位和位置，颜色不表示推断的网络质量；`*` 不染成失败色，缺失的 ASN/地理数据不会被补造。复制和下载使用相同的纯文本，不混入着色节点、命令摘要或装饰状态。
